Campanha Polar

Painel Streamlit para acompanhar vendas, clientes novos, reativações, expansão de mix, adiantamento de pedidos, XP regional e o Budget Anual de 2026.

Visão geral do projeto

A aplicação consulta o Supabase com a identidade do usuário, executa regras analíticas em funções PostgreSQL e consolida os cinco indicadores nas páginas do Streamlit.

Regras gerais de negócio

Participação

  • região com meta positiva na competência;
  • times aceitos: Canais, Time Norte e Time Sul;
  • Time Norte/Sul = Construção; Canais = Canais;
  • sem meta ou meta zero: não participa;
  • admitidos e desligados não têm teto proporcional.

Venda elegível

  • item válido para métricas e venda comercial;
  • exclui bonificação, remessa e transferência;
  • cancelamento deve estar refletido na fonte;
  • bloqueado participa somente pelo faturado;
  • devoluções reduzem o saldo até o mínimo zero.

Evento diário e atribuição

Pedidos elegíveis do mesmo grupo comercial e data formam um único evento. Para mix, a família também integra a chave. Um vendedor recebe 100% do XP; exatamente dois recebem 50% cada. Vendedor ausente, três ou mais participantes, segmento divergente ou mapeamento ambíguo deixam o evento pendente e sem XP.

O realizado anual soma vendas comerciais válidas implantadas em 2026 e subtrai todas as devoluções ocorridas em 2026. A inadimplência não reduz o Budget Anual.

Segurança e autorização

Leitura

Autenticado

Qualquer conta válida do Supabase Auth consulta todas as regiões. Não existe restrição regional por usuário.

Escrita

Cinco editores

Somente as cinco contas cadastradas na allowlist podem alterar adiantamento. A função SQL valida ID e e-mail diretamente no JWT.

  • a senha não é armazenada pelo aplicativo;
  • a sessão é revalidada em cada execução;
  • chaves secretas/service role são rejeitadas;
  • tabelas de adiantamento não têm acesso direto pela API;
  • as RPCs usam security definer e search_path vazio;
  • o salvamento usa versão para detectar alterações concorrentes.

Operação e implantação

Execução local

python -m pip install -r requirements.txt
python -m streamlit run app.py

Configure em .streamlit/secrets.toml apenas SUPABASE_URL e SUPABASE_PUBLISHABLE_KEY.

Preparação do banco

  1. sql/adiantamento_meta.sql
  2. sql/budget_anual.sql
  3. sql/vendas_quadrimestre.sql
  4. sql/clientes_novos.sql
  5. sql/clientes_reativados.sql
  6. sql/mix_produtos.sql

O deploy registrado usa Streamlit Community Cloud, repositório LeoWatanabeAmbar/CampanhaPolar, branch main e arquivo principal app.py.

Erros operacionais principais

  • AUTH_REQUIRED: renovar o login e conferir grants;
  • PERMISSION_DENIED: conta fora da allowlist de edição;
  • INVALID_MONTH: competência fora de setembro–dezembro/2026;
  • INVALID_REGION: região sem meta positiva;
  • CONCURRENT_CHANGE: recarregar a versão atual antes de salvar;
  • contrato desatualizado: reaplicar o SQL indicado no Supabase.
